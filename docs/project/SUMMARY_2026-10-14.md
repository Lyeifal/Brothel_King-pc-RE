#### 2.2 翻译冲突修复
**问题**: Mod翻译文件与游戏本体冲突

```
Exception: A translation for "OFF" already exists at 
game/custom/mods/Example - Price Override/tl/chinese_simplified/mod.rpy:29.
```

**修复**:
- ✅ 删除Mod中重复的通用字符串翻译（ON/OFF/Close）
- ✅ 只保留Mod特有的字符串

**经验**: Mod翻译应避免翻译游戏本体已有的通用UI文本

#### 2.3 Mod API错误修复
**问题**: Mod按钮无法显示

```
Exception: A screen named ('Pricing', 'price_override_config_screen') does not exist.
```

**原因**: `home_rightmenu_add_buttons` 使用了错误的格式（元组列表）

**修复**:
```python
# ❌ 错误格式
"home_rightmenu_add_buttons": [
    (__("Pricing"), "price_override_config_screen")
]

# ✅ 正确格式
"home_rightmenu_add_buttons": ["right_menu_pricing_button"]

# 然后定义按钮screen
screen right_menu_pricing_button():
    textbutton __("Pricing") style_group "rm":
        action Show("price_override_config_screen")
        tooltip __("Configure the advanced pricing system")
```

**结果**: Mod按钮正常工作

## 💡 关键经验总结

### 1. Mod开发最佳实践

**正确的按钮注册格式**:
```python
# Manifest中只提供screen名称列表
"home_rightmenu_add_buttons": ["my_button_screen"]

# 单独定义按钮screen
screen my_button_screen():
    textbutton __("My Button") style_group "rm":
        action Show("my_config_screen")
        tooltip __("My tooltip")
```

**翻译文件注意事项**:
- ❌ 不要翻译通用字符串（ON/OFF/Close/Yes/No等）
- ✅ 只翻译Mod特有的字符串
- ✅ 使用唯一的key前缀避免冲突

**default声明位置**:
```python
# ✅ 正确：在顶层
default my_config = MyConfig()

init -100 python:
    # 其他代码
```
