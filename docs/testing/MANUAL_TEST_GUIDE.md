> 版本: 2026-10-13
> 用途: 重构后的完整回归测试清单

## 📋 测试前准备

### 1. 备份现有存档
```bash
# 备份 game/saves/ 目录
cp -r game/saves game/saves_backup_$(date +%Y%m%d)
```

### 2. 清理缓存
```powershell
# 删除编译缓存
Get-ChildItem -Path "game" -Filter "*.rpyc" -Recurse | Remove-Item -Force
Get-ChildItem -Path "game\cache" -Filter "*.rpyb" | Remove-Item -Force
```

### 3. 启动开发者模式
- 编辑 `game/core/config/options.rpy`
- 确保 `config.developer = True`
- 或在启动时按 Shift+O 测试控制台

## 🚨 常见问题排查

### 问题1: 游戏启动崩溃
**检查**:
- `errors.txt` 或 `traceback.txt` 文件
- 是否清理了 `.rpyc` 缓存
- `game/core/init/` 下的文件是否完整

### 问题2: 女孩无法显示
**检查**:
- `game/custom/girls/` 目录是否有女孩包
- `_BK.ini` 文件是否存在
- 控制台是否有图片加载错误

### 问题3: 结算时崩溃
**检查**:
- `game/core/systems/endday.rpy` 是否有语法错误
- 女孩是否有非法属性值（负数、NaN等）
- 查看 `log.txt` 中的结算日志

### 问题4: 存档无法读取
**检查**:
- 存档文件是否存在
- 是否有 "AutoRepair" 消息
- 尝试删除存档重新测试
