Basic Help

Getting started

To play Brothel King, you need to install the following:

  1. The latest version of the game AND the latest patch (this is very important as while the game is in alpha, the latest patch is required to make it more stable). To install the latest patch, simply unzip it into the 'game\' folder and overwrite existing files.
  2. One or several girl packs. Without girl packs, there is no game. For starters, you can download the Basic Girl Pack from where you got the game. To install a girl pack, unzip the girl folders into the 'game\girls\' folder (create this folder if it doesn't exist). Each folder should be named after a girl's name and contain picture files. Please note that I only provide support for the basic girl pack. User-made girl packs are the responsibility of their own makers.

All the files listed above in their latest versions are available here.

Controls and shortcuts

To advance through the game, left-click or press the space or enter keys. When at a menu, left-click to make a choice, or use the arrow keys to select a choice and enter to activate it.

The following controls can be used in-game:

Right-click allows you to return to the previous screen, or, if on the main screen, to bring up the Options screen. The Options screen (including Save/Load) can be accessed at any moment by using the Esc key.

Middle-click will hide the UI and text to show the background picture. This will only work properly during story events.

Hover your mouse over most of the UI components in-game to access tips and detailed information.

The Ctrl key can be used to skip text faster. By default, it will only skip text you have already seen, but this can be adjusted in 'Preferences' to fast-skip all text.

The following shortcuts allow fast-moving from a screen to another:

h: Home (main menu)
c: Character screen
k: Spellbook
g: Girls screen
b: Brothel screen
w: Wagon screen (once unlocked)
o: Brothel options (once unlocked)
v: Visit city
l: Return to the last visited location
m: Slave market
s: Shop(s)
f: Farm screen (once unlocked)
p: Farm powers (once unlocked)
t: Postings
e: End day
Esc: Save/Options menu

(Native Ren'Py shortcuts still work, but have been replaced by shift+[key] where necessary.)

In-Game help

For more detailed help, including help with the core game concepts and specific screens, click on the ? icon in the top-right of the screen in-game. Cheats are also available from that menu, but be aware that they will disable achievements for good on that playthrough.

What is this game?

Brothel King is another take on Sim Brothel and gets some inspiration from other games, such as Slave Maker. It's made with Ren'Py, my objectives being to make a fun game with a clean UI, good art and a full back story (which isn't yet fully developed). Some of you may not like the story elements, please be aware that there is a 'no story mode' available at NewGame+.

As it is a personal project, my aim is to bring this to a fully playable state sooner than later, but now I got to a point where I really need some help - specifically feedback from players.

Warning
This game contains adult hentai tropes such as prostitution, rape, sexual slavery, hardcore bondage, monsters, bestiality, and so on. I do not condone any of those things in real life: this is just a game, please don't play it if it upsets you. Some of the more hardcore content can be disabled in preferences, but be aware that these settings will not disable some story events that include this type of content.

What is Ren'Py?

This game is based on Ren'Py. Which is excellent.

Ren'Py is a visual novel engine – used by thousands of creators from around the world – that helps you use words, images, and sounds to tell interactive stories that run on computers and mobile devices. These can be both visual novels and life simulation games. The easy-to-learn script language allows anyone to efficiently write large visual novels, while its Python scripting is enough for complex simulation games.

Ren'Py is open source and free for commercial use.

Visit https://www.renpy.org for more information.
